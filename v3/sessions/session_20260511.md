## 技术决策

### 决策 1: 选择 Lightweight Charts 而非 KLineChart

**问题：** 需要选择一个图表库来替代 v2 的 KLineChart

**方案：** 使用 Lightweight Charts v4.1.3

**原因：**
- TradingView 官方开源库，更适合外盘期货
- 更轻量 (50KB vs 200KB)
- 更好的性能
- 更活跃的社区维护
- 更简洁的 API

### 决策 2: 使用原生 JavaScript 而非 React

**问题：** v2 使用 React + Babel Standalone，代码复杂

**方案：** V3 使用原生 JavaScript

**原因：**
- 减少依赖
- 简化代码结构
- 更好的性能
- 更容易维护
- 无需构建工具

### 决策 3: 只使用官方标记工具

**问题：** 如何实现 PDA 标记

**方案：** 优先使用 Lightweight Charts 官方提供的标记工具

**原因：**
- 避免重复造轮子
- 更好的兼容性
- 自动适配库的更新
- 减少维护成本

**可用工具：**
- Series Markers (4 种形状: circle, square, arrowUp, arrowDown)
- Price Lines (5 种线型)
- Custom Primitives (自定义图形)

### 决策 4: 模块化时间格式化功能

**问题：** 时间格式化功能需要在多个地方使用

**方案：** 提取为独立的可复用模块

**原因：**
- 可在多个项目中复用
- 集中管理，易于维护
- 功能完整 (格式化、解析、转换)
- 文档完善

### 决策 5: 通过配置参数控制鼠标交互

**问题：** 如何控制价格轴的鼠标交互行为

**方案：** 使用 Lightweight Charts 的 `handleScroll` 和 `handleScale` 配置选项

**原因：**
- 无需编写自定义代码
- 配置简单直观
- 支持运行时动态修改
- 官方支持，更稳定

## 遇到的问题

### 问题 1: 加载按钮失效

**现象：** 点击加载按钮没有反应，控制台显示语法错误

**原因：** 插入 PDA 标记代码时，第 481 行有多余的 `}`

**解决：** 
```bash
sed -i '481d' v3/docs/kline_viewer.html
```

**教训：** 使用 sed 插入代码时要注意括号匹配

### 问题 2: 时间戳对应错误

**现象：** SSL 标记显示在 16:00 而非 11:00

**原因：** 混淆了 UTC 时间和美东时间

**解决：** 
- 时间戳 1326124800 对应 UTC 16:00 = EST 11:00
- 应使用 1326106800 (对应图表显示的 11:00)

**教训：** API 返回的 `time` 字段就是美东时间，`timestamp` 是对应的 Unix 时间戳，直接使用即可

### 问题 3: 时间格式化功能不工作

**现象：** 输入 12 位数字后失焦，没有自动格式化

**原因：** JavaScript 语法错误导致整个脚本无法执行

**解决：** 删除多余的 `}` 后功能正常

**教训：** 先测试基础功能，再添加新功能

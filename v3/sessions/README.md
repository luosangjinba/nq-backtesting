## 会话管理

### 创建新会话

```bash
# 复制模板
cp v3/sessions/session_template.md v3/sessions/session_$(date +%Y%m%d).md

# 编辑会话文件
vim v3/sessions/session_$(date +%Y%m%d).md
```

### 更新索引

每次创建新会话后，更新本文件的会话索引表。

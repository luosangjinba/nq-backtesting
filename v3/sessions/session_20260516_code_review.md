## 使用指南

### 开发新功能前
1. **查阅 `FUNCTION_REFERENCE.md`**：看是否有可复用的函数或类
2. **查阅 `MODULE_INDEX.md`**：了解相关模块的职责和依赖
3. **检查清单**：
   - [ ] 是否已有类似的 Primitive 可以复用？（`pda-renderer.js`）
   - [ ] 是否已有类似的工具函数？（`utils.js`）
   - [ ] 是否已有类似的 UI 组件？（`context-menu.js`, `pda-form.js`, `pda-detail.js`）
   - [ ] 是否已有类似的状态管理？（`chart.js` 的 `state` 对象）

### 添加新功能后
- 更新相应的文档，保持索引最新
- 如果添加了新的可复用组件，在 `FUNCTION_REFERENCE.md` 中添加示例

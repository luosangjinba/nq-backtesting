## 已知问题

### 时区处理
- Lightweight Charts 使用 UTC 时间
- v2 API 返回的时间戳已经是正确的
- 图表显示的时间可能与输入时间有偏差（需要后续处理）

### 数据格式
- v2 API 返回 `timestamp` 字段（秒级 Unix 时间戳）
- Lightweight Charts 需要 `time` 字段（秒级 Unix 时间戳）
- 当前直接映射，工作正常

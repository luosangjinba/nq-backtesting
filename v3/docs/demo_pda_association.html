PDA 关联交互 Demo

场景：标注完行情段后，需要关联导致反转的 PDA。
问题：如何选择和关联 PDA？
请体验三种方案，选择最符合你工作流程的一种。

方案 A：时间范围内 PDA 列表勾选

✅ 优点

  • 直观，自动显示相关 PDA
  • 不需要记忆 PDA ID
  • 可以看到所有候选 PDA

❌ 缺点

  • PDA 列表可能很长
  • 需要滚动查找
  • 只能关联时间范围内的 PDA

该时间范围内的 PDA（点击选择，选择角色）

方案 B：先选 PDA 再关联

✅ 优点

  • 灵活，可跨时间范围关联
  • 可以在图表上直观选择
  • 支持多次选择

❌ 缺点

  • 需要两步操作
  • 需要先记住要关联的 PDA
  • 可能忘记选择

已选中的 PDA（在图表上点击选择）

在图表上点击 PDA 进行选择

方案 C：输入 PDA ID

✅ 优点

  • 最灵活
  • 可以关联任何 PDA
  • 适合熟悉数据的用户

❌ 缺点

  • 需要记忆或查找 PDA ID
  • 容易输入错误
  • 不直观

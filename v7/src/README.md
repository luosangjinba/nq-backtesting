# V7 Source Boundary

V7 production modules may be added only in roadmap order, with an owning public
contract, machine-readable descriptor, manifest inventory update, independent
harness, and manual acceptance. R1.1–R1.3 activate only pure Session,
activation-generation, TransactionId, and lifecycle/currency contracts; none is
a Session store, scheduler, coordinator, or runtime.

Do not import runtime code from V4, V5, or V6.

# V7 R4.5 Real Lightweight Charts Slice — 2026-07-20

## Boundary Decision

Activate the first real chart-bearing vertical slice without adding a real
market provider. Pin official Lightweight Charts 5.2.0 behind one adapter and
compose a clearly disclosed deterministic NQ/`1m`/ETH foundation workspace
through the existing public owners.

Session Browser remains the route owner and receives Replay Workspace as an
optional surface. Unsupported Session configurations retain the accepted
summary instead of exposing fake controls.

## Current API Audit

Official `IChartApi`, `ITimeScaleApi`, `ISeriesApi`, and awesome-tradingview
references were checked immediately before implementation through agent-reach.
`setData()` replaces the complete ordered series; native logical range is the
correct wall measurement; `subscribeDataChanged()` is invocation evidence, not
paint evidence. No catalogue plugin supplied transaction-level completion.

The adapter therefore uses two animation-frame opportunities and validates
real candle pixels from `takeScreenshot()` before its exact visible receipt.

## Human Review — Accepted

The first review rejected the fixed-width/height chart card, visibly artificial
candle fixture, oversized Replay controls, and centered stale-update overlay.
The corrective pass uses an immersive chart-first route, denser two-hour entry,
varied deterministic OHLC structure, compact controls, and preserves the chart
without a centered message during Manual Next. A second review identified
excessive independent wick lengths and non-tick-aligned prices; the fixture now
uses exact NQ quarter ticks, short power-distributed routine wicks, and sparse
long-wick events, with executable distribution limits. R4.6 remained blocked
until interaction and visual acceptance was recorded.

The user accepted R4.5 on 2026-07-20 after exercising the real workspace. The
accepted boundary includes the immersive chart layout, compact Reset/Next
controls, no centered Manual Next overlay, native drag/zoom wall preservation,
explicit Reset View, and normalized quarter-tick candle structure. The user
also requested that upcoming Reset View, Replay, and Settings work consider
useful V6 interaction patterns without importing its ownership model.

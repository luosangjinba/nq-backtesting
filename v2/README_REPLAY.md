# K线回放功能 - 简化版

## ✅ 已实现的功能

### 1. 右侧边距优化
- K线距离右边缘约2根K线宽度
- 符合主流交易软件习惯

### 2. 增量更新
- 播放更流畅
- 减少重绘开销

### 3. 锁定功能（简化版）
- 通过 🔒 按钮手动锁定
- 通过 📍 按钮恢复跟随

---

## 🎮 使用方法

### 锁定当前位置

```
1. 播放到想要观察的位置（如第10根）
2. 暂停
3. 点击 🔒 按钮
4. 状态栏显示: 🔒 锚点模式
5. 继续播放
6. 视口固定在第10根位置
```

### 恢复跟随最新K线

```
点击 📍 按钮
状态栏显示: 📍 跟随模式
```

## 🎯 应用场景

### 场景 1: 研究特定时间段

```
目标: 观察 9:30-10:00 的价格行为

步骤:
1. 播放到 10:00
2. 暂停
3. 点击 🔒 锁定
4. 继续播放
5. 视口固定，可以看到这个时间段的完整演变
```

### 场景 2: 对比不同位置

```
目标: 对比不同时间点的价格结构

步骤:
1. 播放到第一个关键位置
2. 点击 🔒 锁定
3. 观察一段时间
4. 点击 📍 恢复跟随
5. 播放到第二个关键位置
6. 再次点击 🔒 锁定
```

## 🎨 UI 说明

### 回放控制栏

```
⏮ ⏪ ▶ ⏩ ⏭    🔒 📍
```

- **⏮**: 跳到开头
- **⏪**: 后退 1 根
- **▶/⏸**: 播放/暂停
- **⏩**: 前进 1 根
- **⏭**: 跳到结尾
- **🔒**: 锁定当前位置
- **📍**: 跟随最新K线

### 状态指示

```
11 / 82    02-12 17:00    🔒 锚点模式    1x
```

或

```
11 / 82    02-12 17:00    📍 跟随模式    1x
```

---

## 📋 功能对比

| 模式 | 特点 | 适用场景 |
|------|------|---------|
| 📍 跟随模式 | 自动滚动到最新K线 | 实时监控 |
| 🔒 锚点模式 | 视口固定在锁定位置 | 研究特定时间段 |

## ⚙️ 技术说明

### 简化设计

- ❌ 移除了复杂的自动触发逻辑
- ✅ 只保留手动按钮控制
- ✅ 更可靠、更易用

### 工作原理

```javascript
// 锁定时记录当前索引
replayState.anchorIndex = replayState.currentIndex;

// 播放时判断
if (锁定模式) {
  滚动到锁定的索引
} else {
  滚动到最新索引
}
```

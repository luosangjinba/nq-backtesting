# K线回放锚点模式功能

## 功能说明

实现了"锚点模式"：当用户手动拖动K线图后，新K线会在当前视口的右边缘位置出现，而不是自动滚动回到最新K线。

## 工作原理

### 两种模式

#### 1. 📍 跟随模式（默认）
- 新K线出现时，自动滚动到最新位置
- 最新K线始终保持在视口右侧（带2根K线的边距）
- 适合实时跟踪最新价格

#### 2. 🔒 锚点模式（手动拖动后）
- 用户向左拖动K线后自动激活
- 记录当前视口右边缘的K线索引作为"锚点"
- 新K线在锚点位置出现，视口不移动
- 适合研究特定时间段的价格行为

### 视觉效果

**跟随模式**:
```
播放前: [====K线====]  [空白]|
播放后: [====K线====新]  [空白]|  <- 自动滚动，新K线在右侧
```

**锚点模式**（用户向左拖动后）:
```
用户拖动: [====K线====]  [空白]|
                     ↑ 锚点位置

播放后:   [====K线新==]  [空白]|  <- 新K线在锚点位置出现
                     ↑ 视口不移动
```

## 使用方法

### 激活锚点模式
1. 加载数据并开始回放
2. 用鼠标向左拖动K线图（或使用滚轮）
3. 自动进入锚点模式，状态栏显示 "🔒 锚点模式"

### 恢复跟随模式
- 点击回放控制栏的 📍 按钮
- 或者点击状态栏的 "📍 跟随模式" 文字

### 状态指示

在回放控制栏的右侧会显示当前模式：
- **📍 跟随模式**: 自动跟随最新K线
- **🔒 锚点模式**: 新K线固定在锚点位置

## 技术实现

### 核心逻辑

```javascript
// 监听用户滚动事件
chart.subscribeAction('onScroll', () => {
  replayState.userScrolled = true;
  
  // 记录当前视口右边缘的K线索引
  const visibleRange = chart.getVisibleRange();
  replayState.anchorIndex = Math.floor(visibleRange.to);
});

// 更新显示时判断模式
if (replayState.userScrolled && replayState.anchorIndex !== null) {
  // 锚点模式：滚动到锚点位置
  chart.scrollToDataIndex(replayState.anchorIndex, 0);
} else {
  // 跟随模式：滚动到最新K线
  chart.scrollToDataIndex(currentData.length - 1, 0);
}
```

### 状态管理

```javascript
replayState = {
  userScrolled: false,   // 用户是否手动拖动
  anchorIndex: null      // 锚点K线索引
}
```

## 应用场景

### 场景 1: 研究特定时间段
```
1. 播放到 9:45
2. 向左拖动，查看 9:30-9:45 的完整走势
3. 继续播放，新K线在 9:45 位置出现
4. 可以观察 9:30-9:45 的价格结构如何演变
```

### 场景 2: 对比不同时间段
```
1. 播放到 10:00
2. 向左拖动到 9:30
3. 继续播放，观察 9:30 附近的价格行为
4. 同时看到后续K线如何发展
```

### 场景 3: 固定视角研究
```
1. 找到关键价格区域（如支撑位）
2. 向左拖动，将该区域固定在视口中
3. 播放，观察价格如何与该区域互动
```

## 注意事项

1. **锚点位置计算**
   - 锚点是视口右边缘的K线索引
   - 使用 `chart.getVisibleRange().to` 获取
   - 向下取整确保是整数索引

2. **滚动事件触发**
   - 鼠标拖动会触发 `onScroll` 事件
   - 滚轮缩放也会触发（这是预期行为）
   - 程序化滚动（`scrollToDataIndex`）不会触发

3. **边距保持**
   - 两种模式都保持 `RIGHT_MARGIN_BARS = 2` 的右侧边距
   - 锚点位置也会应用边距

4. **初始化重置**
   - 每次加载新数据时，自动重置为跟随模式
   - 确保用户从干净状态开始

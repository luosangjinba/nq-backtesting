# K线价格密度调整

## 🎯 功能说明

调整K线图的默认价格密度，让K线显示更紧凑。

## 📊 实现原理

通过扩大 Y 轴的价格范围，使相同的屏幕高度显示更多的价格区间，从而让K线看起来更紧凑。

### 技术实现

```javascript
// 在数据加载完成后，自动调整 Y 轴范围
const expandFactor = 1.5;  // 扩大50%的价格范围
const center = (range.from + range.to) / 2;
const newRange = range.range * expandFactor;
```

## 🎨 视觉效果

### 改动前（默认密度）
```
价格范围: 18000 - 18100 (100点)
屏幕高度: 500px
密度: 5px/点
K线: 较大，间距较宽
```

### 改动后（压缩密度）
```
价格范围: 17950 - 18150 (200点)
屏幕高度: 500px
密度: 2.5px/点
K线: 更紧凑，显示更多价格信息
```

## ⚙️ 调整参数

如果需要调整压缩程度，修改 `expandFactor` 值：

```javascript
const expandFactor = 1.2;  // 轻微压缩（扩大20%）
const expandFactor = 1.5;  // 中等压缩（扩大50%）- 当前设置
const expandFactor = 2.0;  // 强力压缩（扩大100%）
```

- **1.0**: 不压缩（原始密度）
- **1.5**: 推荐值（适中的压缩）
- **2.0**: 强压缩（K线很小）

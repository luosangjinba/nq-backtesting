# K线图高度调整

## ✅ 已完成的调整

### 修改内容

**原来**:
```css
#chartContainer {
  flex: 1;           /* 占据所有可用空间 */
  min-height: 0;
}
```

**现在**:
```css
#chartContainer {
  flex: 0 0 60vh;    /* 固定为视口高度的60% */
  min-height: 400px; /* 最小400px */
  max-height: 60vh;  /* 最大60%视口高度 */
}
```

---

## 📊 效果对比

### 改动前
- 图表占据整个垂直空间
- K线可能显得过于拉伸
- 不够紧凑

### 改动后
- 图表高度为视口的60%
- K线显示更紧凑自然
- 下方留有空间
- 最小高度400px确保小屏幕也能正常显示

---

## ⚙️ 调整参数

如果需要调整高度，修改 `#chartContainer` 样式（约第595行）：

```css
flex: 0 0 50vh;    /* 50%视口高度 - 更矮 */
flex: 0 0 70vh;    /* 70%视口高度 - 更高 */
flex: 0 0 60vh;    /* 60%视口高度 - 推荐 */
```

或者使用固定像素：

```css
flex: 0 0 500px;   /* 固定500px高度 */
min-height: 500px;
max-height: 500px;
```

## 📝 说明

- `60vh` = 视口高度的60%
- `min-height: 400px` = 确保最小可用高度
- `max-height: 60vh` = 防止过高
- `flex: 0 0 60vh` = 不伸缩，固定60vh

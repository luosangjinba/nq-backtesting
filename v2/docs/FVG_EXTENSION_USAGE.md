# FVG 扩展功能使用说明

## 功能概述

通过右键菜单控制 FVG（Fair Value Gap）标注的向右扩展，可以灵活调整 FVG 的显示范围。

## 使用方法

### 步骤 1：标记或选择 FVG
**方式 1：右键标记新 FVG**
```
1. 右键点击 K 线
2. 选择"手动标记 PDA" → FVG
3. FVG 自动预览显示
```

**方式 2：使用已有的 FVG**
```
- 从 PDA List 选择 Auto FVG
- 或使用已预览的 Manual FVG
```

### 步骤 2：扩展 FVG

```
1. 右键点击 FVG 区域（矩形范围内）
2. 菜单显示"扩展 FVG" → 悬浮子菜单
   - 扩展 5 根
   - 扩展 10 根
   - 扩展 20 根
   - 扩展到当前位置
3. 选择扩展选项
4. FVG 立即向右延伸
```

## 扩展选项说明

### 固定步长扩展

**扩展 5 根**
- 向右扩展 5 根 K 线
- 适合小幅调整

**扩展 10 根**
- 向右扩展 10 根 K 线
- 常用扩展量

**扩展 20 根**
- 向右扩展 20 根 K 线
- 适合大幅扩展

### 扩展到当前位置

**功能**：
- 将 FVG 扩展到鼠标当前所在的 K 线位置
- 自动计算需要扩展的 K 线数量

**使用场景**：
```
1. 移动鼠标到目标位置
2. 右键点击 FVG
3. 选择"扩展到当前位置"
4. FVG 扩展到鼠标位置
```

**限制**：
- 当前位置必须在 FVG 右侧
- 如果当前位置在 FVG 范围内或左侧，会提示警告

## Toast 提示消息

### 扩展成功
```
✅ FVG 已扩展 10 根 K 线（总计 15 根）
```
- 显示本次扩展的 K 线数
- 显示累计扩展的总数

### 扩展失败
```
⚠️ 当前位置在 FVG 范围内或之前
```
- 扩展到当前位置时，如果位置不合适

## 累加扩展

**特性**：
- 支持多次扩展
- 扩展量会累加

**示例**：
```
1. 第一次扩展 10 根 → FVG 总长度 = 原始 + 10
2. 第二次扩展 5 根  → FVG 总长度 = 原始 + 15
3. 第三次扩展 20 根 → FVG 总长度 = 原始 + 35
```

## FVG 识别机制

### 识别条件

**时间范围**：
- 鼠标位置的 K 线索引在 FVG 的时间范围内
- FVG 范围 = [起始位置 - 1, 起始位置 + 4 + 扩展量]

**优先级**：
- 如果多个 FVG 重叠，选择最近的一个
- Auto PDA 和 Manual PDA 都会被检测

### 右键菜单显示逻辑

**显示"扩展 FVG"**：
- 鼠标位置在 FVG 区域内
- 检测到 Auto FVG 或 Manual FVG

**隐藏"扩展 FVG"**：
- 鼠标位置不在任何 FVG 区域内
- 只显示其他菜单项（复制时间、手动标记 PDA）

## 技术细节

### FVG 数据结构

```javascript
{
  pdaType: 'fvg',
  anchorTime: '2012-01-09 11:20',
  priceHigh: 2357.50,
  priceLow: 2356.50,
  direction: 'bullish',
  extendBars: 15  // 扩展的 K 线数量
}
```

### 默认 FVG 长度

- 原始 FVG 长度：5 根 K 线（起始位置 -1 到 +4）
- 扩展后长度：5 + extendBars

### 边界处理

**右边界**：
- 扩展不会超过图表数据范围
- 自动限制在 `candleData.length - 1`

**左边界**：
- FVG 起始位置固定
- 只能向右扩展，不能向左

### 绘制逻辑

```javascript
// 计算结束索引
const extendBars = pda.extendBars || 0;
const endIdx5 = Math.min(idx + 4 + extendBars, candleData.length - 1);

// 绘制矩形
overlays.push({
  name: 'fvgZone',
  points: [
    { timestamp: candleData[startIdx].timestamp, value: priceTop },
    { timestamp: candleData[endIdx5].timestamp, value: priceBottom }
  ],
  // ...
});
```

## 与其他功能的协调

### 与多 PDA 预览的关系

- 扩展的 FVG 保留在预览列表中
- 可以同时扩展多个 FVG
- 每个 FVG 独立管理扩展量

### 与保存功能的关系

- 扩展信息保存在 PDA 对象中
- 保存 Manual PDA 时，扩展信息会一起保存
- 从 YAML 加载时，扩展信息会恢复

### 与图表切换的关系

- 切换时间周期（TF）后，扩展保持
- 切换日期范围后，扩展保持
- FVG 根据新的图表数据重新绘制

## 注意事项

### 1. FVG 识别精度

- 基于鼠标位置的 K 线索引判断
- 不依赖精确的价格位置
- 只要在 FVG 的时间范围内即可

### 2. 多个 FVG 重叠

- 如果多个 FVG 重叠，会选择最近的一个
- 建议避免创建过多重叠的 FVG

### 3. 扩展量限制

- 理论上无限制
- 实际受图表数据范围限制
- 建议扩展量不超过 50 根（避免过长）

### 4. 只支持 FVG

- 当前只有 FVG 支持扩展
- OB、BSL、SSL 等其他 PDA 类型暂不支持
- 未来可能扩展到其他类型

## 常见问题

### Q: 为什么右键菜单没有"扩展 FVG"选项？

A: 可能的原因：
1. 鼠标位置不在 FVG 区域内
2. 图表上没有 FVG 标注
3. 鼠标位置的 K 线索引无效

### Q: 扩展到当前位置为什么失败？
A: 当前位置必须在 FVG 右侧。如果鼠标在 FVG 范围内或左侧，会提示警告。

### Q: 可以缩短 FVG 吗？

A: 当前版本不支持缩短。未来可能添加负数扩展或"重置扩展"功能。

### Q: 扩展信息会保存吗？

A: 会。扩展信息保存在 PDA 对象的 `extendBars` 字段中，保存 Manual PDA 时会一起保存。

### Q: 可以扩展 Auto PDA 的 FVG 吗？

A: 可以。但 Auto PDA 的扩展不会保存到数据库，只在当前会话有效。

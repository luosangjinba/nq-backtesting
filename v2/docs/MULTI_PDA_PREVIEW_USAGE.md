# 多 PDA 标注同时显示 - 使用说明

## 功能概述

现在可以同时预览多个 Manual PDA，并与 Auto PDA 一起显示在图表上，方便对比不同 PDA 的位置关系。

## 使用方法

### 方式 1：右键连续标记

```
1. 右键点击 K 线 → 选择"手动标记 PDA" → BSL
   → 图表立即显示 BSL 标注

2. 右键点击另一根 K 线 → 选择"手动标记 PDA" → FVG
   → 图表同时显示 BSL + FVG 标注

3. 继续标记更多 PDA...
   → 所有标注同时显示
```

### 方式 2：表单填写 + 预览

```
1. 填写 Manual PDA 表单 → 点击"预览标注"
   → 图表显示第 1 个预览

2. 修改表单（不同时间或类型）→ 点击"预览标注"
   → 图表同时显示第 1 个 + 第 2 个预览

3. 继续填写和预览...
   → 所有预览同时显示
```

## 按钮说明

### "预览标注" 按钮

**默认状态**（灰色）：
- 文字：预览标注
- 功能：将当前表单的 PDA 添加到预览列表

**已预览状态**（红色）：
- 文字：清除标注
- 功能：从预览列表中移除当前表单对应的 PDA

### "清除所有预览" 按钮

- 功能：一键清除所有预览的 Manual PDA
- 提示：显示清除的数量

## 智能去重

**相同 PDA 的判断标准**：
- 相同的 Anchor Time
- 相同的 PDA 类型（BSL/SSL/FVG/OB）

**行为**：
- 重复预览相同 PDA → 更新而非重复添加
- Toast 提示："已更新预览（N 个）"

## 与 Auto PDA 的关系

**独立显示**：
- PDA List 选择 Auto PDA → 显示在图表上
- Manual PDA 预览 → 同时显示在图表上
- 两者互不干扰，可以同时对比

**示例**：
```
图表上同时显示：
- 1 个 Auto PDA（来自 PDA List）
- 3 个 Manual PDA（预览列表）
= 总共 4 个 PDA 标注
```

## 使用场景

### 场景 1：对比不同类型的 PDA

```
目标：查看某个时间段内的 BSL、SSL、FVG 位置关系

操作：
1. 右键标记 BSL（高点）
2. 右键标记 SSL（低点）
3. 右键标记 FVG（缺口）
→ 三个 PDA 同时显示，清晰对比
```

### 场景 2：对比不同时间的相同类型 PDA

```
目标：查看多个 BSL 的分布

操作：
1. 右键标记第 1 个 BSL
2. 右键标记第 2 个 BSL
3. 右键标记第 3 个 BSL
→ 多个 BSL 同时显示，观察流动性分布
```

### 场景 3：Manual PDA vs Auto PDA

```
目标：对比手动标记和自动检测的差异

操作：
1. PDA List 选择一个 Auto BSL
2. 右键标记一个 Manual BSL（稍有偏差）
→ 两个 BSL 同时显示，对比位置差异
```

### 场景 4：验证 PDA 组合

```
目标：验证某个交易设置的 PDA 组合

操作：
1. 标记入场 PDA（FVG）
2. 标记止损 PDA（SSL）
3. 标记目标 PDA（BSL）
→ 完整的交易设置可视化
```

## 清除策略

### 清除单个预览

**方法 1**：修改表单到对应 PDA → 点击"清除标注"
```
1. 表单填写为 BSL @ 2012-01-09 11:20
2. 点击"清除标注"
→ 只清除这个 BSL，其他预览保留
```

**方法 2**：点击"重置"按钮
```
→ 清除当前表单对应的预览
```

### 清除所有预览

**方法**：点击"清除所有预览"按钮
```
→ 一键清空所有 Manual PDA 预览
→ Auto PDA 不受影响
```

## 注意事项

### 1. 预览数量

- 理论上无限制
- 建议不超过 10 个（避免图表拥挤）
- 预览过多时可以分批清除

### 2. 表单状态

- 表单填写不完整时，仍可预览（会尝试构建 PDA）
- 预览失败会显示错误提示
- 按钮状态根据当前表单内容动态更新

### 3. 图表切换

- 切换时间周期（TF）后，预览保持
- 切换日期范围后，预览保持
- 预览的 PDA 会根据新的图表数据重新绘制

### 4. 保存行为

- 点击"保存 Manual PDA"后，预览保持
- 如需清除，手动点击"清除标注"或"清除所有预览"

## 快捷工作流

### 工作流 1：快速标记多个 PDA

```
1. 右键标记 → 自动预览
2. 右键标记 → 自动预览
3. 右键标记 → 自动预览
4. 观察对比
5. 点击"清除所有预览"
```

### 工作流 2：逐个验证和保存
```
1. 右键标记 PDA 1 → 自动预览
2. 检查位置 → 满意 → 点击"保存"
3. 点击"清除标注"（清除 PDA 1 预览）
4. 右键标记 PDA 2 → 自动预览
5. 检查位置 → 满意 → 点击"保存"
6. 重复...
```

### 工作流 3：批量标记后统一保存

```
1. 右键标记 PDA 1、2、3 → 同时预览
2. 整体检查位置关系
3. 逐个保存（表单会自动填充）
4. 点击"清除所有预览"
```

## 常见问题

### Q: 为什么点击"预览标注"没有添加新的预览？

A: 如果当前表单的 PDA（时间 + 类型）已经在预览列表中，会更新而非添加。Toast 提示会显示"已更新预览"。

### Q: 如何清除特定的一个预览？

A: 修改表单到对应的 PDA（时间 + 类型），然后点击"清除标注"按钮。

### Q: 清除所有预览会影响 Auto PDA 吗？

A: 不会。"清除所有预览"只清除 Manual PDA 预览，Auto PDA（来自 PDA List）不受影响。

### Q: 预览的 PDA 会保存到数据库吗？

A: 不会。预览只是临时显示，需要点击"保存 Manual PDA"才会保存到数据库。

### Q: 可以预览多少个 PDA？

A: 理论上无限制，但建议不超过 10 个，避免图表过于拥挤。

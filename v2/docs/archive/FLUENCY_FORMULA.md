# 流畅度计算公式

## 综合评分

```
流畅度 = 加权得分 × 100
```

评分范围：0-100 分

---

## 五个指标及权重

| 指标 | 权重 | 说明 |
|------|------|------|
| 方向一致性 | **42%** | 同方向（含平K）K线占比 |
| 推进效率 | **22%** | 净推进距离 / 总价格变化 |
| 连续性 | **16%** | 最大连续同方向K线占比 |
| 实体占比 | **15%** | 平均实体大小 / 平均K线范围 |
| 斜率稳定性 | **5%** | 斜率波动的一致程度 |

---

## 各指标计算公式

### 1. 方向一致性（42%）

```
方向一致性 = (主导方向K线数 + 平K线数) / 总K线数
```

- 每根K线判断：收盘 > 开盘 → 涨(↑)，收盘 < 开盘 → 跌(↓)，收盘 = 开盘 → 平(—)
- 主导方向 = 涨或跌中数量较多的一方
- **平K线按整体趋势方向计入**（避免平K拖低评分）

示例：6涨 + 3平 + 0跌 → 方向一致性 = (6+3)/9 = 1.0

---

### 2. 推进效率（22%）

```
推进效率 = |终点价格 - 起点价格| / Σ(每根K线的最高-最低)
```

- 1.0 = 直线推进，无回撤（完美）
- 0.5 = 净推进占总移动的一半
- 低值 = 大量来回震荡，净推进小

---

### 3. 连续性（16%）

```
连续性 = 最大连续同方向K线数 / 总K线数
```

- 高值 = 有持续推进（流畅）
- 低值 = 频繁反转（犹豫）

示例：↑↑↑↑↑↓↑↑↑ → 最大连续5根 → 连续性 = 5/9 = 0.556

---

### 4. 实体占比（15%）

```
实体占比 = 平均(|收盘-开盘|) / 平均(最高-最低)
```

- 高值 = 实体大、影线小（果断）
- 低值 = 实体小、影线大（犹豫）

---

### 5. 斜率稳定性（5%）

```
斜率稳定性 = max(1 - std(斜率)/|mean(斜率)|, 方向一致性×0.5)
```

- 斜率 = 每根K线的 收盘 - 开盘
- 高值 = 斜率稳定（匀速推进）
- 低值 = 斜率波动大（忽快忽慢）
- **归零时用方向一致性×0.5替代**，避免极端拖分

---

## 加权计算

```
加权得分 = 0.42 × 方向一致性
         + 0.22 × 推进效率
         + 0.16 × 连续性
         + 0.15 × 实体占比
         + 0.05 × 斜率稳定性

流畅度 = 加权得分 × 100
```

---

## 特殊处理

### 首根K线剔除

计算前自动剔除首根K线，因为：
- 首根可能是反转K线（如流畅上涨的第一根是长阴线）
- 会影响方向一致性和连续性计算

### 时间对齐

输入时间按所选周期向下取整对齐：
- 1H周期：`16:23 → 16:00`，`01:45 → 01:00`
- 15m周期：`16:23 → 16:15`，`01:47 → 01:45`
- 5m周期：`16:23 → 16:20`，`01:47 → 01:45`

---

## 计算示例

**时间区间：** 2012-01-09 16:00 → 2012-01-10 01:00（1H周期）

剔除首根后 9根K线：
- 方向序列：↑ ↑ ↑ ↑ — ↑ ↑ — —
- 6涨 + 3平 = 方向一致性 1.0
- 实体占比 0.511
- 连续性 0.444（最大连续4根）
- 推进效率 0.5
- 斜率稳定性 0.5

```
加权得分 = 0.42×1.0 + 0.22×0.5 + 0.16×0.444 + 0.15×0.511 + 0.05×0.5
         = 0.42 + 0.11 + 0.071 + 0.077 + 0.025
         = 0.703

流畅度 = 0.703 × 100 = 70.3 分
```

---

## 权重设计理由

| 指标 | 权重 | 理由 |
|------|------|------|
| 方向一致性 | 42% | 肉眼最直观的感受，方向一致=流畅 |
| 推进效率 | 22% | 反映"走得顺不顺"，直线推进vs来回震荡 |
| 连续性 | 16% | 反映"有没有持续推进"，频繁反转=犹豫 |
| 实体占比 | 15% | 影线大小影响观感，但不是主要因素 |
| 斜率稳定性 | 5% | 太不稳定，权重低避免拖分 |

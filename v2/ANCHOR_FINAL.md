# K线回放锚点模式 - 最终版本

## ✅ 功能已实现

锚点模式现在完全可用，支持两种激活方式：

### 方式 1: 手动锁定按钮 🔒（推荐）

**最简单、最可靠的方式**

1. 播放到想要固定的位置
2. 暂停
3. 点击 🔒 按钮
4. 继续播放
5. 视口固定在锁定位置

### 方式 2: 鼠标拖动（自动触发）

**更自然的交互方式**

1. 播放中或暂停时
2. 用鼠标拖动K线图（按住左键拖动）
3. 自动激活锚点模式
4. 继续播放
5. 视口固定在拖动时的位置

## 🎯 两种模式对比

### 📍 跟随模式（默认）

**特点**:
- 自动跟随最新K线
- 最新K线始终在视口右侧
- 适合实时监控

**视觉**:
```
[====K线====新]  [空白]|
            ↑ 自动滚动
```

### 🔒 锚点模式（手动激活）

**特点**:
- 视口固定在锁定位置
- 新K线在左侧（视野外）出现
- 适合研究特定时间段

**视觉**:
```
[====K线新==]  [空白]|
         ↑ 视口固定，新K线在左侧
```

## 🔧 技术细节

### 工作原理

1. **锚点 = 锁定时的播放索引**
   ```javascript
   replayState.anchorIndex = replayState.currentIndex;
   ```

2. **播放时判断模式**
   ```javascript
   if (replayState.userScrolled && replayState.anchorIndex !== null) {
     // 锚点模式: 滚动到锚点索引
     chart.scrollToDataIndex(replayState.anchorIndex, 0);
   } else {
     // 跟随模式: 滚动到最新索引
     chart.scrollToDataIndex(currentData.length - 1, 0);
   }
   ```

3. **防止误触发**
   ```javascript
   // 程序化滚动时设置标志
   window.isProgrammaticScroll = true;
   chart.scrollToDataIndex(...);
   
   // 100ms后重置标志
   setTimeout(() => {
     window.isProgrammaticScroll = false;
   }, 100);
   ```

### 状态管理

```javascript
replayState = {
  userScrolled: false,   // 是否激活锚点模式
  anchorIndex: null      // 锚点索引
}
```

## 🎨 UI 元素

### 回放控制栏

```
⏮ ⏪ ▶ ⏩ ⏭  📍 🔒
```

- **⏮**: 跳到开头
- **⏪**: 后退 1 根
- **▶/⏸**: 播放/暂停
- **⏩**: 前进 1 根
- **⏭**: 跳到结尾
- **📍**: 恢复跟随模式
- **🔒**: 锁定当前位置（激活锚点模式）

### 状态指示器

```
11 / 82    02-12 17:00    📍 跟随模式    1x
```

或

```
11 / 82    02-12 17:00    🔒 锚点模式    1x
```

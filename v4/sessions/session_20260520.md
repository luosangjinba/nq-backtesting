# Session 2026-05-20: V4 日线聚合修复 + 时间输入格式化

## 目标
修复 V4 日线聚合错误，添加时间输入自动格式化功能。

## 关键决策
- 数据时间戳为美东时间（ET），不做 UTC 转换
- CME session 日线分界为 18:00 ET（前一天18:00 ~ 当天16:59），不是 22:00 UTC
- 日线聚合排除 17:00-17:59 休市时段（`extract(hour from ts) = 17`）
- 时间输入格式化：8位→YYYY-MM-DD 00:00，12位→YYYY-MM-DD HH:mm
- 命令失败不盲目重试，分析原因后换策略（用绝对路径）

## 完成内容
1. 新建 `v4/src/utils.js` — formatTimeInput() 函数
2. 修改 `v4/src/ui/toolbar.js` — 导入 formatTimeInput，绑定 blur 自动格式化，handleLoad 中也先格式化
3. 修改 `v4/v4_api.py` — 日线聚合三处修复：
   - anchor offset 从 22*3600 (22:00 UTC) 改为 18*3600 (18:00 ET)
   - SQL 排除 17:00-17:59 休市时段
   - 时间输出用 timezone.utc 的 fromtimestamp 避免系统时区偏移

## 验证
- 2012-01-10 ET 日线：Open=2347.5, High=2378.25, Low=2347.5, Close=2360.0 ✓
- 时间输入 `201201090200` → 失焦后 `2012-01-09 02:00` ✓
- 时间输入 `20120109` → 失焦后 `2012-01-09 00:00` ✓

## 发现
- 17:00-17:59 有30根1m bar（休市时段仍有数据），不排除会导致 last(close) 取到 17:59 的值而非 16:59
- datetime.fromtimestamp() 在 UTC+8 系统上会把 epoch 值偏移，用 tz=timezone.utc 可避免
- NQ 交易时段：18:00-16:59 ET，周末周五16:59收盘到周日18:00开盘
- 假日有异常收盘时间（如13:14），暂不特殊处理

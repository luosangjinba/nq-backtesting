# Session 2026-05-20: V4 日线聚合修复 + 时间输入格式化 + 图表显示优化

## 目标
修复 V4 日线聚合错误，添加时间输入自动格式化，优化图表显示（低周期防挤压 + 高周期去 padding）。

## 关键决策
- 数据时间戳为美东时间（ET），不做 UTC 转换
- CME session 日线分界为 18:00 ET（前一天18:00 ~ 当天16:59），不是 22:00 UTC
- 日线聚合排除 17:00-17:59 休市时段（`extract(hour from ts) = 17`）
- 时间输入格式化：8位→YYYY-MM-DD 00:00，12位→YYYY-MM-DD HH:mm
- 命令失败不盲目重试，分析原因后换策略（用绝对路径）
- API 返回 `{ bars, requestedRange }` 格式，前端用 requestedRange 过滤 padding bar
- bar-store 分离全量数据（含 padding）和显示数据（不含 padding）
- 图表显示策略：少量 bar 用 fitContent()，大量 bar 用 setVisibleLogicalRange 从起始位置显示
- fixLeftEdge/fixRightEdge 设为 false，允许自由拖动滚动
- 遇到不确定的 API 时查文档，不要猜

## 发现
- 17:00-17:59 有30根1m bar（休市时段仍有数据），不排除会导致 last(close) 取到 17:59 的值而非 16:59
- datetime.fromtimestamp() 在 UTC+8 系统上会把 epoch 值偏移，用 tz=timezone.utc 可避免
- NQ 交易时段：18:00-16:59 ET，周末周五16:59收盘到周日18:00开盘
- fixLeftEdge/fixRightEdge=true 会锁死图表边缘，导致高周期少量 bar 被拉伸填满 canvas
- LightweightCharts v5 的 series.data().size API 不确定，改为由调用方传入确定的 chartData.length
- 假日有异常收盘时间（如13:14），暂不特殊处理

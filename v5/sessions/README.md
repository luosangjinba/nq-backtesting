# V5 Session Handoffs

Session files are targeted handoffs for completed or active V5 steps.

## Organization Rules

- Session filenames include the date and step number.
- Step numbers are historical execution IDs, not phase numbers.
- Keep session files in place; do not rename historical handoffs just to change
  display order.
- Do not load all historical sessions by default. Read the current step handoff
  and only the older session files needed for the specific task.
- `v5/TODO.md` lists completed steps in numeric order. This directory preserves
  the detailed handoff for each step.
- `v5/docs/V5_PHASE_ROADMAP.md` is the phase-level source of truth. Session
  files are execution records.
